# mysql_fdw

This extension adds the foreign data wrapper for databases that offer interaction through the MySQL protocol.

Created by [Enterprise DB](https://www.enterprisedb.com/).

Link to source [here](https://github.com/EnterpriseDB/mysql_fdw).

Can be used for adding mysql-compatible databases as foreign servers.
